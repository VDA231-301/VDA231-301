# Example Classification

The agent should classify every user request into one or more example categories.

## Material Modelling

Examples related to materials:

- Simple Material Definition
- Multiple Source Material
- Material with Stack
- Material and Surface Identifiers

## Component Modelling

Examples related to components:

- Component Master Modelling
- Component Instance Traceability
- NGID-based Component Identification

## Specification Modelling

Examples related to requirements and specifications:

- Material with Specification Customization
- Specification Hierarchies
- Layer-specific Requirements
- Color-dependent Requirements

## Testing Modelling

Examples related to tests and results:

- VDA 270 Results
- VDA 278 Results
- Complete Testing Projects

## Future Modelling

Examples based on draft entities or future schema extensions.

## Classification Rules

The agent should first identify:

1. the business scenario
2. the primary entity
3. the modelling objective

before selecting the example category.
