# Multiple Source Material

## Business Scenario

A supplier uses the same material type from more than one approved source.

The material fulfills the same business and technical requirements but may originate from different suppliers or be identified by different specifications.

The receiving OEM needs to understand which approved material sources are available for the component.

## Objective

This example demonstrates how alternative approved material sources can be documented using the VDA 231-301 data model.

## Learning Goals

After reviewing this example, the reader should understand:

- how multiple approved material sources are represented
- how material specifications can differ between sources
- how the MaterialSources entity is used
- how a ComponentMaster references its approved sources

## Relevant Entities

### ComponentMaster

The material or component being described.

### MaterialSources

Alternative approved material source definitions.

### Specification

Material specifications applicable to a material source.
